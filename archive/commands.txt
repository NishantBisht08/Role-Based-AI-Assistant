Starting the PostgreSQL (psql) Shell manually:
1. Open SQL Shell (psql)
Press Windows
Search for SQL Shell (psql)
Open it.

2. Enter the connection details

Server [localhost]:
Press Enter (accepts localhost).

Database [postgres]: rbac_db

Type:
rbac_db
Press Enter.

Port [5432]:
Press Enter (default port).

Username [postgres]: app_user

Type:
app_user

Press Enter.

Password for user app_user:

Type your password. (1234 here)

Note: The password will not be visible while typing.

Press Enter.



3. Successful connection
If everything is correct, you'll see something like:

psql (18.0)
Type "help" for help.
rbac_db=>

The prompt
rbac_db=>

means you're now connected to the rbac_db database and can execute SQL commands.



Useful Commands

List all tables:
\dt

Describe a table:
\d table_name

View all records:
SELECT * FROM table_name;

List all databases:
\l

Connect to another database:
\c database_name

Clear the screen:
\! cls

Exit psql:
\q
